# 工作开关与监听状态

开关文件保存在程序当前活动的状态版本中，由程序管理。MCP、Hook、后台轮询与终端观察器使用同一状态代次。暂停/恢复和目标可用性变化会使旧代次失效，旧会话的迟到事件及未完成终端采集不会重放。

| 状态 | 姓名引导 | 读取/采集/上传 | 后台行为 |
| --- | --- | --- | --- |
| unconfigured | 不询问 | 拒绝 | 不监听 |
| outside_work | 不询问 | 当前会话拒绝 | 其他合法工作文件仍由全局后台管理 |
| offline | 不询问 | 拒绝 | 清除内存基线，保留已有快照 |
| manual_pause | 不询问 | 拒绝 | 同上 |
| config_pending / config_invalid | 不询问 | 拒绝 | 等待修正 MD 并重新应用 |
| migrating | 不询问 | 拒绝新操作 | 等待迁移完成或重试 |
| awaiting_name | 主动询问 | 仅允许姓名登记 | 不采集 |
| active | 不重复问 | 按路径白名单处理 | 只检查已登记清单 |

后台实现是限于清单的定时检查，不是整盘文件监听。状态、工作文件及归档目标中的符号链接/目录联接不能用来跨越路径边界。稳定检测同时使用文件属性和内容 SHA-256；后台启动、恢复或注册状态变化时重建基线。

终端命令只能在工作白名单内注入追踪。观察器读取短期健康状态及控制版本，状态过期时停止记录路径和指纹。未完成采集在状态变化后被丢弃。支持范围之外的原生写入不以目录扫描兜底。

可用性检查使用有超时的独立进程进行目录及访问检查，不会创建缺失的目标根目录。真实写入还可能因 ACL、配额或瞬时网络故障失败；只有完成无覆盖提交并校验后才报告 stored。

暂停不等同于删除已有归档或关闭客户端模型服务。MCP 仍可返回暂停状态并接受工作开关命令，但不读取工作文件。后台与普通会话相互独立，生活会话不会被自动归档。

编辑 MD 后重新执行安装命令应用配置。迁移会等待正在执行的数据操作完成，保留旧状态版本并校验已登记快照；成功后切换稳定入口。工作目录被移除时，相应未上传快照保持 scope_paused，只有重新纳入范围并被 Agent 明确处理后才继续上传。
